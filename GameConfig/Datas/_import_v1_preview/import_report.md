## ⚠️ 记忆 ID 语义冲突（源表 vs 生产表）

生产表 `记忆配置表.xlsx` 是**旧剧情**的记忆体系（M01–M31，一条记忆对应一个剧情认知，例如「试着修理」「共同的期待」）；V1.0 源表是**新剧情**体系（M01–M19，一条记忆对应一个物品部件观察点 + 少量对话记忆）。两者 ID 空间重叠但含义不同，直接覆盖会让旧引用指错记忆：

| 记忆ID | V1.0 剧情含义 | 生产表（旧剧情）含义 |
|---|---|---|
| M07 | 相机记忆3 | 布偶的补缀 |
| M08 | 钟表记忆1 | 小满的纸条 |
| M09 | 钟表记忆2 | 继续陪伴 |
| M10 | 娃娃记忆1 | 断开的读取模块 |
| M11 | 娃娃记忆2 | 仍在的存储部分 |
| M12 | 娃娃记忆3 | 试着修理 |
| M13 | 收录机记忆1 | 没能接稳的焊点 |
| M14 | 收录机记忆2 | 电话里未说完的事 |
| M15 | 收录机记忆3 | 共同的期待 |
| M16 | 收录机记忆4 | 同型号零件 |
| M17 | 娃娃记忆4 | 朋友留下的声音 |
| M18 | 磁带记忆1 | 交出去的零件 |
| M19 | 磁带记忆2 | 录音里的称呼 |

受影响选项 10 个：
- `O032902` 需要 M12（剧情=娃娃记忆3 / 生产=试着修理）
- `O040902` 需要 M16（剧情=收录机记忆4 / 生产=同型号零件）
- `O043002` 需要 M17（剧情=娃娃记忆4 / 生产=朋友留下的声音）
- `O043102` 需要 M16（剧情=收录机记忆4 / 生产=同型号零件）
- `O043402` 需要 M10（剧情=娃娃记忆1 / 生产=断开的读取模块）; M16（剧情=收录机记忆4 / 生产=同型号零件）
- `O051202` 需要 M08（剧情=钟表记忆1 / 生产=小满的纸条）
- `O060702` 需要 M16（剧情=收录机记忆4 / 生产=同型号零件）
- `O064602` 需要 M12（剧情=娃娃记忆3 / 生产=试着修理）; M18（剧情=磁带记忆1 / 生产=交出去的零件）
- `O070702` 需要 M19（剧情=磁带记忆2 / 生产=录音里的称呼）
- `O071602` 需要 M18（剧情=磁带记忆1 / 生产=交出去的零件）

**结论**：这不是「谁写错了」，而是两代剧情的记忆表并存。V1.0 上线就必须整体替换 `记忆配置表.xlsx`（剧情节点表同时整体替换），不能只换一部分。

生产表有、V1.0 不用的记忆：`['M20', 'M21', 'M22', 'M23', 'M24', 'M25', 'M26', 'M27', 'M28', 'M29', 'M30', 'M31']`。源表只用到 M01–M19 + M98/M99，与它们**ID 不重叠**，可以原样保留（旧存档兜底），也可以随旧节点表一起清掉。
